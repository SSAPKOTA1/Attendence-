Trip Inn Attendance – Shift Scheduling and Time Tracking

Static overview of the existing web app (plain wireframe, fake data). Purpose: give a designer the full set of screens, roles and content to redesign.

Design request. Make this feel simple and modern for hotel staff. Today it has about 15 menu items shown at once for a manager, which feels overwhelming. Group navigation into 4–5 sections, add a clear "first steps" checklist for new admins, and make the tablet and phone views large and easy to tap. Keep it German-first with an English toggle (DE / EN).

Who uses it

  • Manager / Admin (desktop): build the roster, approve requests, check times, export payroll as Excel.
  • Employee (phone): see own shifts, request leave, enter wishes, view own times.
  • Shared tablet at reception (kiosk): staff clock in/out with a PIN. Must work at a glance, big buttons.
